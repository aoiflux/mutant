# Bytes Examples

Run from repository root (compile, then run the bytecode it writes
beside the source):

```bash
mutant gen --src examples/bytes/bytes_cursor_elf_sample_demo.mut --dev
mutant examples/bytes/bytes_cursor_elf_sample_demo.mu --dev
```

Scripts:
- bytes_cursor_elf_sample_demo.mut
- bytes_cursor_sample_demo.mut

Notes:
- Some scripts use examples/data or root fixtures in examples.
