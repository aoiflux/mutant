# Basics Examples

Run from repository root (compile, then run the bytecode it writes
beside the source):

```bash
mutant gen --src examples/basics/code.mut --password <password>
mutant examples/basics/code.mu --dev --password <password>
```

- code.mut
- enums_example.mut
