# Basics Examples

Run from repository root (compile, then run the bytecode it writes
beside the source):

```bash
mutant gen --src examples/basics/code.mut --dev
mutant examples/basics/code.mu --dev
```

Scripts:
- code.mut
- bitwise_flags.mut
- closures.mut
- control_flow.mut
- enums_example.mut
- for_loop_control.mut
- recur.mut
- string_forms.mut
- structs_example.mut
