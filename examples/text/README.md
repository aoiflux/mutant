# Text Examples

Run from repository root (compile, then run the bytecode it writes
beside the source):

```bash
mutant gen --src examples/text/fuzzy_matching_example.mut --password <password>
mutant examples/text/fuzzy_matching_example.mu --dev --password <password>
```

Scripts:
- fuzzy_matching_example.mut
- phishing_url_analyzer.mut
- regex_example.mut
- text_matching_example.mut
- text_pipeline_ioc_normalizer.mut
- wordlist_mutator.mut
