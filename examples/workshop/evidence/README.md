# Evidence for case QUILLDROP

The workshop investigates **synthetic** evidence generated by
[`fsagen`](https://github.com/aoiflux/fsagen). Nothing here is real, nothing is
malicious, and the whole corpus is reproducible from a seed.

## Why synthesized evidence is better for a workshop

Three reasons, and the third is the one that matters:

1. **It is legal and shareable.** Real triage collections carry real user data.
2. **It fits on a USB stick.** A disk image does not.
3. **It is deterministic.** `--seed 88412` produces the same bytes on every
   laptop in the room. Which means every student's report has the **same
   SHA-256** — and `11_verdict.mut` can prove it. Reproducibility stops being a
   slide and becomes a thing that either matches or does not.

## Build it

```bash
# from the repository root
fsagen --seed 88412 \
       --playbook examples/workshop/evidence/quilldrop.playbook.yaml \
       --timeline examples/workshop/evidence/case_quilldrop.body \
       examples/workshop/evidence/case_quilldrop
```

or run `build_evidence.ps1` (Windows) / `build_evidence.sh` (Linux/macOS),
which does the same thing and then prints what it produced.

**Run it on NTFS if you can.** Two of the artifacts — Mark-of-the-Web and the
alternate data stream on the implant — are NTFS features. On ext4/APFS the
playbook still runs and the other four tools still work; `07_dropzone.mut`
simply reports that the MoTW stream is not present, which is the honest answer.

## The bodyfile is the important one

`--timeline …body` writes a **Sleuth Kit bodyfile**:

```
MD5|name|inode|mode|UID|GID|size|atime|mtime|ctime|crtime
```

That is the single most valuable artifact in the collection, because the live
filesystem only hands you *one* timestamp through `fs_stat` — while the bodyfile
hands you **four**, and four timestamps can disagree with each other.

Mutant reads it directly:

```mutant
let rows, err = bodyfile_parse("examples/workshop/evidence/case_quilldrop.body");
let timeline  = mactime(rows);                    // one row per distinct time, MACB flags
let events, _ = events_from(rows, "bodyfile");    // normalized -> Sigma / ECS / Timesketch
```

Two builtins, and the fsagen corpus is a supertimeline.

## Regenerating just the timeline

If students modify files and want a fresh bodyfile without rebuilding the corpus:

```bash
fsagen --timeline examples/workshop/evidence/case_quilldrop.body \
       examples/workshop/evidence/case_quilldrop
```

## Fallback if fsagen is unavailable

Every tool in `07_`–`12_` checks whether its input exists and, when it does not,
prints exactly what to provide and exits. None of them fabricate a result. So a
student with no evidence still gets a program that runs, reads, and explains
itself — they just cannot reach a verdict, which is the correct behaviour.
