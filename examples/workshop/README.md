# Case QUILLDROP — a two-hour DFIR workshop in Mutant

Ten programs, none longer than eighteen lines, that take one workstation's
files and turn them into a signed handover. Read them in order: each one starts
where the last one stopped.

Everything here targets **Mutant v2.5.0**, the released version. Nothing in the
story calls a builtin that shipped after the tag, so an attendee who downloaded
the release can run all ten.

## Build the evidence first

Nothing is committed. The corpus is generated by
[`fsagen`](https://github.com/aoiflux/fsagen) from a seed, so every laptop in
the room holds the same bytes:

```
go install github.com/aoiflux/fsagen@v0.1.0
.\examples\workshop\evidence\build_evidence.ps1      # or build_evidence.sh
```

Run it from the repository root. See [evidence/README.md](evidence/README.md)
for what it produces and which findings need NTFS. Until you run it, each of
the ten prints one line saying what is missing and exits cleanly — that is what
the `.golden` files record.

## Running a file

Mutant compiles a `.mut` to a `.mu`, then executes the `.mu`:

```
mutant gen --src examples/workshop/01_scene.mut --dev
mutant examples/workshop/01_scene.mu --dev
```

or `.\examples\workshop\run.ps1 01_scene` (`run.sh` on Linux/macOS), which does
both. Always from the repository root — the scripts name their evidence with
repository-relative paths.

`--dev` uses the built-in public development key so nothing prompts. Drop it and
both commands ask for a password; use the same one for both, or pass
`--password-file <path>` or `--password-stdin`. A password on the command line
lands in the process table, which is why that form is gone.

**Run from PowerShell or cmd, not Git Bash or WSL.** Secure mode halts when the
host looks like an analysis sandbox, and Git Bash on Windows trips the WSL
detector at confidence 90: `sandbox detected, execution halted for security`.
Use a native shell, or pass `--compat` to downgrade that to a warning.

### Language gotchas worth knowing before you start

Every row here is true of **v2.5.0**. The last two are fixed on the development
branch and will not bite you on a later release.

| Gotcha | What you see | Fix |
|---|---|---|
| Fallible builtins return `(value, err)` | binding one name hands you the whole pair | `let v, e = f(x);` — and `_` says the failure is deliberately ignored |
| Not every builtin is fallible | the second name is always null | `mactime`, `slice`, `len`, `extract_iocs` return one value |
| There is no `null` literal | `undefined variable: null` | a bare `return;` yields null; test with `is_null()` |
| A program ending in a loop prints `<iterator>` | a stray line after your output | end on a `putln`, not on a `for` |
| No string literal inside `${...}` | parse error naming the line *inside* the string | bind a local, then `${local}` |
| Builtins are not first-class values | `map(xs, defang)` fails | `map(xs, fn(d) { return defang(d); })` |
| `while` / C-style `for` inside a `for…in` | `loop cursor was replaced on the stack` | `for…in` nests inside `for…in` fine |
| `rand.` `sort.` `assert.` `gunzip.` under the VM | works in the REPL, fails in a compiled `.mu` | use the underscore spelling |

## More examples to pick from (each self-contained, ~15–25 lines)

Short, standalone snippets — great for "here's a thing Mutant makes easy"
moments. All run with **no input**.

| File | "Mutant makes it easy to…" |
|------|----------------------------|
| [ioc_extract.mut](ioc_extract.mut) | pull every IP / domain / URL / email / hash out of a blob of text in one call, then defang it |
| [typosquat.mut](typosquat.mut) | flag look-alike domains (`paypa1.com`) with string-similarity scoring |
| [decode_payload.mut](decode_payload.mut) | peel encoding layers off an obfuscated payload (base64 / hex) |
| [jwt_inspect.mut](jwt_inspect.mut) | decode a JWT's header and claims |
| [top_talkers.mut](top_talkers.mut) | count connections per source IP and rank the top talkers |
| [cert_inspect.mut](cert_inspect.mut) | generate a CA cert and read its subject / validity / fingerprint |
| [ip_triage.mut](ip_triage.mut) | tell internal vs external IPs, test CIDR membership, expand a CIDR |
| [log_parse.mut](log_parse.mut) | turn unstructured log lines into structured fields with one regex |
